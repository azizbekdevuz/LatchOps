# LatchOps brand sources

The five files here are the supplied rasters, copied unchanged.

| File | Role |
|---|---|
| `latchops-lockup-tagline.png` | Full mark, wordmark, and “EVIDENCE-BACKED GIT RECOVERY” |
| `latchops-wordmark.png` | Compact horizontal wordmark for dark surfaces |
| `latchops-wordmark-light.png` | Same wordmark inside a light pill |
| `latchops-app-icon.png` | Square app icon |
| `latchops-symbol-mono.png` | Single-color symbol. The source has scattered edge specks |

Production files are cropped from these and live under `apps/web/public/brand/` and `apps/web/src/app/icon.png`. No SVG master was drawn. The glossy 3D mark does not have a clean vector reconstruction, so the site uses the rasters.
